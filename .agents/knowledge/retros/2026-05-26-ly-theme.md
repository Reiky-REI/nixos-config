# Ly 显示管理器美化 — Catppuccin Mocha + Colormix 动画

## 变更内容

**文件**: `modules/desktop/default.nix`

**改动**: 将 `services.displayManager.ly.enable = true;` 展开为完整配置块，添加：
- **Catppuccin Mocha 配色**: bg=`#1e1e2e`, fg=`#cdd6f4`, border=`#cba6f7` (Mauve)
- **Colormix 渐变动画**: Mauve → Teal → Rosewater 三色平滑过渡
- **大时钟**: 英文格式显示星期 + 时间
- **布局美化**: 居中文本、标题 "NixMEOW"、38 字符输入框

## 验证

```bash
sudo nixos-rebuild build --flake /etc/nixos#NixMEOW
# ✅ 构建成功
```

## 技术细节

- Ly 配置通过 `services.displayManager.ly.settings` 写入 `/etc/ly/config.ini`
- 颜色格式 `0xSSRRGGBB` 支持样式位（`0x01`=粗体）
- `animation_timeout_sec = 0` 表示动画永不停止
- `blank_box = true` 保持输入框区域不透明以保证可读性
- 当前系统主题统一为 Catppuccin Mocha + Mauve accent

## 注意事项

- ⚠️ 不要直接用 `nixos-rebuild switch` (NVIDIA PRIME 崩溃风险)
- 应用方式：下次重启时自动生效，或手动 `sudo nixos-rebuild switch`（需注意风险）
