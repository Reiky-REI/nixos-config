# WPS Office HiDPI 修复 — 2x 缩放

## 背景

WPS Office 在 2560x1600 高 DPI 笔记本屏幕上 UI 元素、备注字体、演讲模式均偏小喵~ 其他 Qt 应用显示正常喵~

## 改动

**文件**：`home/Reiky-REI/apps/office.nix`

| 改动 | 说明 |
|------|------|
| 函数参数扩展 | `{pkgs, ...}` → `{config, pkgs, lib, ...}` |
| **L1** — 原生 DPI 配置 | `home.activation.setupWpsHiDPI` 注入 `common\useSystemDpi=1` 到 `Office.conf` |
| **L2** — 桌面文件覆盖 ×4 | `xdg.desktopEntries` 覆盖 wps/wpp/et/wpspdf，注入 `QT_SCALE_FACTOR=2` |
| **L3** — 演讲备注字体 | `home.activation.setupWpsNotesFont` 将 `SlideShowPresenterNotesFontSize` 20→30（1.5x） |

## 设计说明

- **三层兜底**：L1 在终端启动时生效喵~ L2 在桌面启动器/图标启动时生效喵~ L3 单独处理演讲者模式字体喵~
- **幂等性**：激活脚本通过 grep 检查已有的配置行，避免重复注入喵~
- **仅作用于 WPS**：用 `xdg.desktopEntries` 而非全局 `home.sessionVariables`，不影响其他 Qt 应用喵~

## 验证

- `nixos-rebuild build` ✅

## 注意事项

- L2 只在通过桌面图标/启动器打开 WPS 时生效（`env QT_SCALE_FACTOR=2 wps %F`）喵~ 终端 `wps` 走 L1 的 DPI 原生方案喵~
- `Qt::AA_EnableHighDpiScaling` 属性在 WPS 的嵌入式 Qt 中不一定被启用，所以 L1 可能不奏效，届时全靠 L2 兜底喵~
