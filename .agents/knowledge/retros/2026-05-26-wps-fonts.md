# 复盘: 2026-05-26 WPS 字体修复 + 分支清理

## 背景
WPS Office 找不到 Windows 字体，全部文字回退为单一中文字体。
同时清理积累的 stale 分支/worktree。

## 改动

| 类型 | 文件 | 说明 |
|------|------|------|
| fix | `modules/common/default.nix` | 修复 serif/sansSerif 配反 |
| feat | 同上 | 新增 6 个字体包: noto-cjk-serif, liberation_ttf, arphic-ukai, arphic-uming, wqy_zenhei, wqy_microhei |
| feat | 同上 | 扩展 fontconfig localConf 覆盖 8 个 Windows 字体族 |
| chore | 分支清理 | 删除 8 个已合并分支 + 2 个 stale worktree |

## Windows 字体映射

| Windows 字体 | 映射到 |
|-------------|--------|
| SimSun / NSimSun | AR PL UMing → Noto Serif CJK SC |
| SimHei | WenQuanYi Zen Hei → Noto Sans CJK SC |
| KaiTi | AR PL UKai → Noto Serif CJK SC |
| FangSong | AR PL UKai → Noto Serif CJK SC |
| Microsoft YaHei | WenQuanYi Micro Hei → Noto Sans CJK SC |
| Microsoft JhengHei | WenQuanYi Micro Hei → Noto Sans CJK SC |
| Times New Roman | Liberation Serif → Noto Serif |
| MingLiU / PMingLiU | AR PL UMing |

## 验证
- `nixos-rebuild build` ✅

## 注意事项
- ⚠️ 字体配置需要 reboot 或 switch 才生效（build 只构建不激活）
- 字体变化不涉及内核/服务重启，switch 在此场景相对安全
