# 复盘: 2026-05-26 WPS 字体修复 + 分支清理

## 背景
WPS Office 在 Linux 上找不到 Windows 字体，全部文字回退为单一中文字体。
同时清理之前积累的 stale 分支/worktree。

## 改动

| 类型 | 文件 | 说明 |
|------|------|------|
| fix | `modules/common/default.nix` | 修复 serif/sansSerif 配反（Noto Sans 写成 serif，Noto Serif 写成 sansSerif） |
| feat | 同上 | 新增 `wqy_zenhei` / `wqy_microhei` 中文字体包 |
| feat | 同上 | 新增 fontconfig localConf，映射 6 个 Windows 字体（SimSun/SimHei/微软雅黑/微软正黑/楷体/仿宋）到 Linux 等价字体 |
| chore | 分支清理 | 删除 8 个已合并分支（本地+远程），删除 2 个 stale worktree |

## Windows 字体映射表

| Windows 字体 | 映射到 |
|-------------|--------|
| SimSun (宋体) | Noto Serif CJK SC |
| SimHei (黑体) | WenQuanYi Zen Hei |
| Microsoft YaHei (微软雅黑) | WenQuanYi Micro Hei |
| Microsoft JhengHei (微软正黑) | WenQuanYi Micro Hei |
| KaiTi (楷体) | Noto Serif CJK SC |
| FangSong (仿宋) | Noto Serif CJK SC |

## 验证
- `nixos-rebuild build --flake /etc/nixos#NixMEOW` ✅

## 注意事项
- 字体映射依赖 fontconfig，只有 WPS 走 fontconfig 字体查找时生效
- 如果 WPS 直接硬编码字体文件路径，此方案可能不生效，届时需要 symlink 方式补充
- `wqy_zenhei` / `wqy_microhei` 大约各 10-15MB，对系统负担很小
