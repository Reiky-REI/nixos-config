## 申请内容

将 **OpenClaw**（github.com/openclaw/openclaw, 376k+ stars）个人 AI 助手网关集成到 NixOS 配置中喵~ 启用微信通道和 QMD 本地记忆喵~ 

## 为什么需要

用户已在 cc-switch 中将 OpenClaw 列为可见应用（`visibleApps.openclaw = true`），但尚未实际安装喵~ 通过 OpenClaw 可实现：
- **微信远程添加笔记** — 手机微信发消息，自动写入 Obsidian 知识库
- **AI 自动整理文档** — OpenClaw 内置 Skills 系统 + MCP 工具调用
- **多通道统一入口** — 微信 / WebUI 统一接入 AI 助手

## 具体方案

### A. `flake.nix` — 新增 input

在 `inputs` 区块添加：

```nix
openclaw = {
  url = "github:openclaw/nix-openclaw";
  inputs.nixpkgs.follows = "nixpkgs";
};
```

在 outputs 参数列表中添加 `openclaw` 参数喵~ 

### B. 新建 `home/Reiky-REI/apps/openclaw.nix`

```nix
{ config, pkgs, lib, inputs, ... }:

let
  inherit (inputs) openclaw;
in {
  imports = [ openclaw.homeManagerModules.default ];

  programs.openclaw = {
    enable = true;

    documents = ./documents;

    config = {
      gateway = {
        mode = "local";
        auth.token = "REIKY-OPENCLAW-GATEWAY-2026";
      };

      models.providers.anthropic.apiKey = {
        source = "env";
        provider = "default";
        id = "ANTHROPIC_API_KEY";
      };

      channels.weixin.enable = true;
      memory.backend = "qmd";
    };

    runtimePlugins = [ "weixin" ];

    bundledPlugins = {
      summarize.enable = true;
      peekaboo.enable = true;
    };
  };

  home.sessionVariables = {
    ANTHROPIC_API_KEY = "$(cat /run/agenix/ai_api_key_REIKY_REI)";
  };
}
```

### C. `home/Reiky-REI/apps/default.nix` — 导入

在 `imports` 列表末尾追加 `./openclaw.nix` 喵~ 

## 预期影响

- **新增 flake input**：`github:openclaw/nix-openclaw`，首次 build 会下载约 500MB 依赖喵~ 
- **新增 systemd user service**：`openclaw-gateway` 自启动喵~ 
- **新增环境变量**：`ANTHROPIC_API_KEY` 通过 agenix 解密注入喵~ 
- **不影响现有功能**：OpenClaw 独立运行，不与现有工具冲突喵~ 

## 验证方式

```bash
sudo nixos-rebuild build --flake /etc/nixos#NixMEOW   # 验证编译

# 部署后：
systemctl --user status openclaw-gateway               # 服务运行中

# 手动初始化微信通道：
openclaw plugins install "@tencent-weixin/openclaw-weixin"
openclaw config set plugins.entries.openclaw-weixin.enabled true
openclaw gateway restart
openclaw channels login --channel openclaw-weixin       # 扫码绑定
openclaw channels status --probe                        # 验证通道
```
