# NixMEOW 已知问题

> 本文档记录 NixMEOW 系统中尚未验证、存在争议或需要进一步研究的问题

## 未验证的理论

| 假设 | 说明 | 验证方式 |
|------|------|---------|
| 信息边界理论 | 个体差异是信息流动不对称的结果 | 构造不同信息流动速度的场景，观察独立性变化 |
| 亲疏远近模型 | 圈层结构影响交互行为 | 设计多 MEOW 协作场景，验证信任机制 |
| 涌现个体性 | 个体性通过交互历史涌现 | 追踪 MEOW 的行为模式演化 |
| 宪法稳定性 | 博弈论宪法能约束行为 | 设计违反宪法的场景，验证惩罚机制 |

## 待研究问题

| 问题 | 说明 | 研究方向 |
|------|------|---------|
| MEOW 的最优粒度 | 一个 MEOW 应该包含多少能力？ | 实验不同粒度的 MEOW，观察协作效率 |
| 继承的深度限制 | 继承链应该有多长？ | 测试多层继承的复杂度和维护成本 |
| 能力的组合爆炸 | 大量能力如何管理？ | 设计能力索引和检索机制 |

## 缺失设计

| 问题 | 说明 | 严重程度 |
|------|------|---------|
| manifest.json 格式 | 没有定义 MEOW 的配置格式 | 高 |
| 委托机制设计 | 没有定义跨 MEOW 的请求/响应协议 | 高 |
| 边界控制机制 | 没有定义如何防止越级访问 | 中 |
