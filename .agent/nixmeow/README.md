# NixMEOW 系统

> 探索性分支：涌现式智囊体系统设计

## 概述

NixMEOW 系统是一个探索性的项目，旨在研究：

- 信息边界理论
- 涌现式个体性
- 多MEOWgent协作

## 与蓝图的关系

- **蓝图分支** (`ai/blueprint-design`)：实用主义的人机交互系统
- **NixMEOW分支** (`ai/nixmeow-system`)：探索性的涌现式智囊体系统

两者是不同的研究方向，但可以相互借鉴。

## 核心概念

- **MEOW**：一切文件的集合 + 信息边界
- **MEOWgent**：MEOW + 行为能力 + 自我意识
- **咪格**：MEOWgent的独特行为模式

## 研究方向

1. 信息边界理论的形式化
2. 涌现式个体性的研究
3. 多MEOWgent协作机制
4. 宪法的博弈论基础
