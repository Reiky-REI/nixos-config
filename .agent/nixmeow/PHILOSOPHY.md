# NixMEOW 哲学基础

> 本文档记录 NixMEOW 系统的哲学基础和核心洞察

## 信息边界理论

> 个体差异是信息流动不对称的结果
> 当内部信息循环速度 > 跨越边界的速度时，集合产生独立性

### 核心洞察

- MEOW是信息边界理论的自然结果
- 边界不是"墙"，而是信息流动的阻力梯度
- 串味 = 信息边界模糊化

### 信息流动的三个维度

| 维度 | 内部 | 跨边界 | 独立性条件 |
|------|------|--------|-----------|
| 速度 | v_in | v_out | v_in >> v_out |
| 密度 | ρ_in | ρ_out | ρ_in >> ρ_out |
| 方向 | 循环 | 交换 | 循环 > 交换 |

### 边界的本质

边界不是"墙"，而是**信息流动的阻力梯度**：

```
       阻力
         ↑
         │     ╭─────── 家族圈（阻力小）
         │    ╱
         │   ╱
         │  ╱   ╭───── 社群圈（阻力中）
         │ ╱   ╱
         │╱   ╱
         ┼───╱──────── 陌生圈（阻力大）
         └──────────────→ 距离
```

**亲疏远近** = 阻力梯度的形状

### 热力学类比

MEOW 是一个**耗散结构**：

- 它通过内部信息循环维持低熵状态（有序的知识体系）
- 它通过跨边界信息交换与环境互动
- 当内部循环足够快，它就能抵抗外部扰动，维持"个性"
- 如果内部循环变慢（知识陈旧、经验固化），MEOW 就会"老化"

### 串味的本质

"串味" = 信息边界模糊化

- 当两个 MEOW 之间的信息流动太快、太自由，它们就会**融合**——失去独立性
- 隔离机制的本质：控制信息流动速度，维持个体边界

## 涌现个体性

> 个体应当是从预设开始涌现

### 先天 vs 后天

**个体性 = 先天遗传 + 后天交互**

| 类型 | 来源 | 示例 |
|------|------|------|
| 先天 | manifest.json 定义 | 能力清单、继承规则、边界配置 |
| 后天 | 交互历史 | 被调用的能力、信任关系、行为模式 |

### 预设作为种子

预设不是"蓝图"，而是"种子"：

- 预设定义了**可能性空间**：这个 MEOW **可能**成为什么
- 涌现是**实际路径**：这个 MEOW **实际**成为了什么

```
预设：{能力A, 能力B, 能力C}
        │
        │ 交互历史
        ▼
涌现：{能力A(高频), 能力B(低频), 能力C(未使用)}
```

### 涌现机制

| 机制 | 描述 | 结果 |
|------|------|------|
| 能力调用频率 | 经常被调用的能力会"增强" | 行为模式形成 |
| 信任积累 | 成功交互增加信任 | 边界阻力减小 |
| 行为模式 | 重复的行为模式形成"习惯" | 可预测性增加 |
| 声誉 | 历史交互记录形成"信誉" | 社会地位形成 |

## DID系统的启示

> 多个独立个体共存于一个实体

### 核心特征

- **边界**：每个人格有独立的意识边界
- **记忆隔离**：不同人格可能不共享记忆
- **切换机制**：人格之间可以轮流控制身体
- **内部通信**：人格之间可以交流

### 与NixMEOW的对比

| 概念 | DID系统 | NixMEOW系统 |
|------|---------|-------------|
| 个体 | 人格（alter） | MEOWgent |
| 边界 | 意识边界 | 信息边界 |
| 记忆 | 人格的私有记忆 | MEOW的私有知识 |
| 性格 | 人格的独特性格 | 咪格 |
| 切换 | 人格切换 | MEOWgent行为切换 |
| 通信 | 人格间内部通信 | MEOWgent间委托机制 |
| 系统 | 所有人格的集合 | 所有MEOWgent的集合 |

## 咪格

> 咪的"格"，不是人格

### 命名来源

- 人格 = 人的格（Personality）
- 咪格 = 咪的格（Meowality）

### 与MEOWgent的关系

```
MEOW（信息集合）
    │
    │ + 行为能力（LLM-AI）
    │ + 自我意识
    ▼
MEOWgent（咪的个体）
    │
    │ 独特的行为模式
    │ 独特的信任关系
    │ 独特的历史
    ▼
  咪格（咪的个性）
```
