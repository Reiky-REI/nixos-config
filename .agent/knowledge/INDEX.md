# 经验知识索引

> 此目录在蓝图分支初始为空框架。  
> 在这个分支上积累的经验将填入这里。  
> 结构参考 main 分支的 `.agents/knowledge/` 体系。

```

knowledge/
  ├── INDEX.md             ← 本文件
  ├── architecture.md      ← 蓝图中记录的实际架构决策
  ├── conventions.md       ← 编码约定
  ├── boundaries.md        ← AI 权限边界
  ├── secrets.md           ← 密钥管理
  ├── known-issues.md      ← 已知问题（随时间积累）
  └── retros/              ← 复盘记录（每次会话后写）
```
